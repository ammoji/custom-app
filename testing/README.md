# HamaraSetu — Testing Workbooks

Two Excel files for the family-testing team:

1. **kirana-mart-features.xlsx** — catalog of every feature shipped so far
2. **kirana-mart-test-cases.xlsx** — ~85 detailed test cases (positive / negative / edge)

Both are generated by `build_testing_workbooks.py` in this folder.

## How to generate the .xlsx files (one-time, ~2 min)

In PowerShell from the project root:

```powershell
# Install the one Python dependency we need
pip install openpyxl

# Run the generator
cd testing
python build_testing_workbooks.py
```

You should see:

```
Building features workbook: ...\kirana-mart-features.xlsx
  ~78 features written.
Building test cases workbook: ...\kirana-mart-test-cases.xlsx
  ~85 test cases written.
Done. Upload both .xlsx files to Google Drive.
```

Both files appear next to the script.

If `python` is not on your PATH, try `py` instead, or install Python from
https://www.python.org/downloads/ (check "Add to PATH" during install).

## Uploading to Google Drive

1. Open https://drive.google.com
2. Click + New → File upload
3. Select **both** `.xlsx` files
4. Right-click each → Open with → Google Sheets
5. Sheets auto-converts; original .xlsx stays as a backup
6. File → Share → Anyone with the link → Editor → Copy link
7. Send the link to your testers

Google Sheets preserves all the formatting, frozen rows, and dropdown
validations from the .xlsx files.

## Updating after future PRs ship

When new features land, edit `build_testing_workbooks.py`:

- Add new feature entries to the `FEATURES = [...]` list
- Add new test cases to the `TEST_CASES = [...]` list
- Re-run `python build_testing_workbooks.py`
- Re-upload the two `.xlsx` files to Google Drive (replace previous)

Or just edit the Google Sheets directly if you prefer — the script is a
re-generator, not the only source of truth. Whatever's in Drive is what
testers see.
